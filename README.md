## 📌 Overview

SmartCare AI is a full-stack healthcare platform that leverages Artificial Intelligence, Machine Learning, Computer Vision, and Blockchain technology to improve healthcare accessibility, patient management, and medical decision-making.

The platform enables patients to receive AI-assisted health guidance, discover nearby specialists, book appointments, manage medical records securely, and access intelligent healthcare services through a unified ecosystem.

---

## 🚀 Key Features

### 🤖 AI Symptom Analysis

* AI-powered chatbot for symptom assessment
* Specialist recommendations based on predicted conditions
* Interactive healthcare assistance

### 📅 Smart Appointment Management

* Doctor discovery and appointment scheduling
* Real-time appointment tracking
* Patient-doctor interaction portal

### 🔐 Secure Medical Records

* Blockchain-backed medical record storage
* Immutable and tamper-resistant patient history
* Controlled access management

### 🪪 Doctor Verification

* OCR-based identity verification
* Secure registration workflow
* Multi-level authentication

### 🤳 Face Recognition Login

* TensorFlow-based biometric authentication
* Secure doctor login system

### 🫁 AI X-Ray Diagnosis

* Automated chest X-ray analysis
* Detection support for:

  * COVID-19
  * Pneumonia
  * Tuberculosis

### 🧠 Mental Health Assessment

* Guided mental wellness evaluation
* Personalized recommendations and resources

### 🎙 Voice Assistance

* Voice-enabled navigation
* Improved accessibility and user experience

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/srijaaa05/SmartCare-AI.git
cd SmartCare-AI
```

### Install Dependencies

Frontend

```bash
cd react-app
npm install
```

Backend

```bash
cd ../server
npm install
```

Python Services

```bash
cd ../py-side
pip install -r requirements.txt
```
